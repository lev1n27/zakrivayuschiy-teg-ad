# Закрывающий тег

Проектная работа Яндекс Практикума: страница-рефлексия о пройденном пути в модулях вёрстки.

Ссылка на репозиторий: https://github.com/lev1n27/zakrivayuschiy-teg-ad

Опубликованный сайт: https://lev1n27.github.io/zakrivayuschiy-teg-ad/

## Что сделано

- Резиновая вёрстка на `clamp()` и CSS-переменных, адаптация под экраны до 375px.
- Вариативный шрифт Inter с настройкой толщины через `font-variation-settings` и акцентный пиксельный шрифт PressStart2P.
- Фон страницы из трёх градиентов, зафиксированный при прокрутке.
- Восемь карточек этапов обучения с лейблами: режим смешивания `hard-light`, обводка текста через `@supports` с фоллбэком на `text-shadow`.
- Уникальные CSS-фильтры для изображений, включая множественный.
- Анимированная иконка сердца: переходы для наведения и нажатия, ключевые кадры для клика.
- Эффекты кнопок при наведении и фокусе, модальное окно на элементе `dialog`.
